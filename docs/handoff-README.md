# Tidequill: handoff package

Prepared October 17, 2026.

| File | What it is |
| --- | --- |
| `Tidequill-Product-Requirements.pdf` | The full requirements document (56 pages), including the architecture and roadmap diagrams. Start with the sections "v1: the site that runs itself" and "Discipline". |
| `Tidequill-Product-Requirements.md` | The same document as Markdown, for a repository or wiki. The two diagrams appear only in the PDF. |
| `Tidequill-Admin-Mockups.pdf` | 12 annotated screens. Screens 1 to 8 are v1; 9 to 12 show the full platform after v1. |
| `prototype/` | Clickable static HTML for every screen. Open `prototype/index.html` in a browser; works offline. |

Where the v1 section and later sections of the requirements disagree, v1 wins.
All names, numbers and content in the mockups are sample data.
The mockups are design references, not production code: the real admin is specified as a Svelte app on the Action registry.
